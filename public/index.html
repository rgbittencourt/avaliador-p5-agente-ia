1. Importar relatório do aluno (PDF)

Selecione o PDF preenchido no modelo oficial da P5. O aplicativo preserva páginas, linhas e colunas e, em seguida, interpreta semanticamente os campos para separar a tabela e os blocos do relatório. Somente o texto extraído é enviado à API configurada — nunca o PDF nem as imagens.
A interpretação acontece automaticamente. Use o botão para repetir a leitura semântica depois de revisar o PDF.
